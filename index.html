Git & Command Line Cheatsheet

Quick reference guide for everyday Git workflows and shell commands.

🔍
Git Basics

Setup & Staging

  • git init

    Initialize a brand new local repository in current folder.

  • git status -s

    Display working directory status in compact short format.

  • git add .

    Stage all changed, modified, and newly created files.

  • git commit -m "feat: message"

    Commit staged changes with a descriptive commit message.

Branching

Branches & Merging

  • git switch -c <branch>

    Create a new branch and immediately switch into it.

  • git branch -a

    List all local and remote tracking branches.

  • git merge <branch>

    Merge specified branch into your current active branch.

  • git branch -d <branch>

    Safely delete a branch that has already been merged.

Remotes

Sync & GitHub

  • git clone <repo-url>

    Download an existing remote repository to local machine.

  • git remote -v

    List all configured remote origin URLs and fetch/push targets.

  • git push -u origin main

    Push local commits and set upstream tracking branch.

  • git pull --rebase

    Fetch and replay local commits on top of incoming remote branch.

Inspection

History & Diffs

  • git log --oneline --graph

    Visual compact representation of branch history and commits.

  • git diff --staged

    Show line-by-line differences of staged changes ready to commit.

  • git show HEAD

    Inspect metadata and full unified diff of the most recent commit.

  • git blame <file>

    Show author, timestamp, and commit hash for each line of a file.

Undo & Stash

Safe Reverts

  • git stash push -m "wip"

    Temporarily shelve uncommitted work to give you a clean tree.

  • git stash pop

    Restore previously stashed changes and remove from stash list.

  • git restore --staged <file>

    Unstage file modifications without losing your actual edits.

  • git commit --amend --no-edit

    Add newly staged changes directly into the previous commit.
