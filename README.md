# Git & Command Line Cheatsheet

A modern, interactive developer cheatsheet grid built with semantic HTML5, CSS Grid, and Vanilla JavaScript.

## Features
- **Real-Time Search:** Instant filtering across command syntax, flags, and descriptions.
- **Category Navigation:** Filter by Git Basics, Branching, Remotes, Inspection, and Undo/Stash.
- **One-Click Copy:** Click-to-copy code snippets with animated toast feedback.
- **Developer Aesthetics:** Clean dark-mode palette, monospace typography, and responsive grid layout.
- **Keyboard Shortcuts:** Press `/` anywhere to focus search immediately.

## Preview
Open `index.html` in your browser.
